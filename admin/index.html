Outil de rédaction — HNet Media

Génère la fiche JSON d'un article à coller dans content/articles.json.

⚠️ Cet outil n'est pas un espace d'administration sécurisé. Il n'y a ni identifiants, ni base de données, ni sauvegarde automatique côté serveur — conformément à la phase actuelle du projet (aucune base de données connectée). Toute personne ayant l'URL peut l'utiliser. Ne l'exposez pas publiquement (gardez-le hors ligne ou protégé par l'authentification basique de votre hébergeur) tant qu'un vrai système d'authentification n'est pas branché. Le JSON généré doit être collé manuellement dans content/articles.json, puis le site doit être reconstruit avec node build.js.
Ne jamais inventer de source. Laisser vide si aucune source externe.
